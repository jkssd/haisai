# 标注规范（矩形靶框 + 中心圆 → 靶心）

> 目标：训练 YOLOv8-pose 从「矩形靶框」回归 4 个角点，并结合「中心圆」得到精确靶心坐标。
> 标注的一致性直接决定最终能否稳定得到亚像素级的靶心，请严格按本规范执行。

---

## 1. 类别

| id | 名称 | 含义 |
|----|------|------|
| 0  | `target` | 一个完整靶子（一块靶板/靶纸） |

一张图里有几个靶子就标几个实例。

## 2. 关键点（7 个，顺序固定）

| 序号 | 名称 | 位置 |
|------|------|------|
| 0 | `tl` | 靶框**左上**角 |
| 1 | `tr` | 靶框**右上**角 |
| 2 | `br` | 靶框**右下**角 |
| 3 | `bl` | 靶框**左下**角 |
| 4 | `center` | 中心圆的**圆心**（= 靶心） |
| 5 | `r_left` | 中心圆的**左极点**（沿靶框水平轴） |
| 6 | `r_right` | 中心圆的**右极点** |

- 第 5、6 点用于表达**圆的大小**：半径 = `|r_right - r_left| / 2`。
- 靶子类型（大/中/小）**不是手填的**，由 `半径 ÷ 靶框半边长` 这个比例自动推导，见第 3 节。
- 工具里点完四个角后会自动定位中心圆并放好 5/6 两点，通常只需微调。

- 顺序为**顺时针**：TL → TR → BR → BL。顺序错了模型学不会，务必检查（工具里角点上有编号）。
- 4 个角点是**透视四边形**的角，不是轴对齐外接矩形。
- `center` 标在**中心圆的圆心**：
  - 靶面只有一圈圆 → 取该圆的圆心；
  - 有多层同心圆（如白圆内套小黑点）→ 仍取**最外层可见圆**的圆心，不要取小黑点的视觉中心；
  - 圆心被弹孔/反光破坏时，用圆的残余弧段估计圆心，并在 `notes` 里注明。

## 3. 靶子类型：按「圆 / 靶框」比例聚类

比例 `ratio = 半径 / (靶框平均边长 / 2)`，与拍摄距离无关。

实测（省赛 5 张图 / 15 个靶子）：

| 类型 | ratio 簇中心 | 阈值（当前标定） |
|------|------|------|
| 大 `target_large` | 0.665 | `ratio >= 0.553` |
| 中 `target_medium` | 0.442 | `0.328 <= ratio < 0.553` |
| 小 `target_small` | 0.213 | `ratio < 0.328` |

- 同一型号在不同距离下 ratio 稳定在 ±0.005 内，三种型号之间的间隔 > 0.2，区分度足够。
- 阈值存在 `data/size_classes.json`，由 `python3 pose.py radius-stats --apply` 自动聚类生成；
  标完新场景后用同一条命令复算（如果新场景是同三种型号，阈值应基本不变）。
- **外观不作为分类依据**：白圆/蓝圆/黑底白圆在同一型号里都会出现。

## 4. 圆必须落在靶框内

- 圆心必须在靶框四边形内，且整个圆不被靶框裁掉；否则判定为干扰（墙上的圆点、球、反光），
  不采纳，把第 4/5/6 点的可见性置 `v=0`（表示"这个靶子没标圆"），训练时自动忽略。
- 找不到圆时就保持 `v=0`，**不要凭想象把半径拖大** —— 错误的圆会污染类型分类。

## 5. 边界与可见性

每个关键点带可见性 `v`：

| v | 含义 | 何时使用 |
|---|------|----------|
| 2 | 可见且标注准确 | 默认 |
| 1 | 被遮挡 / 出画，但可合理推断 | 桌沿挡住底边、靶子出画一半 |
| 0 | 完全不可见且无法推断 | 几乎不用 |

规则：
1. 角点落在画面外时，**放到画面边界上**并置 `v=1`（工具会自动裁剪并置 1）。
2. 被前景遮挡但仍能通过两条边延长线交会出角点时，正常标注，`v=1`。
3. 靶子被遮挡超过一半、或边长 < 12 px 无法可靠定位时，**不标**这个实例。
4. 靶子只露出一个角（无法确定另外三个角）时，**不标**。

## 6. 靶框取哪条边

- 取**靶面外轮廓**：靶纸/靶板的外边界。
- **不要**包含：支架、三脚架、靶板后面的纸箱、阴影、贴纸边缘的白边（如果有明显双边，取靶面本体）。
- 靶纸贴在墙上且边缘与墙面几乎同色时，取**能连续追踪到的边界**，宁可略内收也不要跳到墙砖缝上。

## 7. 不做的事

- 不要为了「看起来正」而把四边形拉成矩形。
- 不要在靶框上多点、少点，只有 4 个角点。
- 不要标注非靶子物体（灯、球、水袋等）。
- 不要跨图复制粘贴坐标（同一连拍序列也必须逐张对齐，相机有位移）。

## 8. 每个场景先标 20 张的抽样要求

> 这 20 张决定了第一版粗模型的分布，务必**覆盖形态**而不是只标连拍的相邻帧。

每个场景至少覆盖：

| 维度 | 要求 |
|------|------|
| 距离/尺寸 | 最近、最远、中等各 ≥ 4 张（同一场景内靶子边长差异可能 5 倍以上） |
| 角度 | 正面、左/右斜视、俯/仰视 各 ≥ 3 张 |
| 数量 | 1 靶、2 靶、3 靶的画面都要有 |
| 遮挡 | 有遮挡（桌沿/支架/前景）≥ 3 张 |
| 光照 | 逆光、强反光、偏暗 各 ≥ 2 张 |
| 画质 | 轻微运动模糊 ≥ 2 张（实际测试会拍到） |

标完这 20 张后，先用 `eval` 之外的**目视检查**确认角点顺序无误，再开始训练 —— 顺序错 1 张的影响大于少标 5 张。

## 9. 标签文件格式

`data/annotations/<scene>/<stem>.txt`，每行一个实例（YOLO-pose）：

```
cls  cx cy w h  x1 y1 v1  x2 y2 v2  x3 y3 v3  x4 y4 v4  x5 y5 v5  x6 y6 v6  x7 y7 v7
```

`cls` = 0/1/2 分别对应 大/中/小（由比例推导，写盘时自动算）。

- 全部为**归一化**到 `[0,1]` 的坐标（除以图像宽/高）；
- `w h` 是 4 个角点的外接矩形宽高；
- 关键点顺序见第 2 节；`v=0` 表示该点未标注（例如没找到圆时的 4/5/6 点）；
- 视角差异大时 `w h` 与真实靶面尺寸不成比例，属正常现象（模型用角点，不用框）。

示例（1920×1080，一个「中」靶，一行）：

```
1 0.194010 0.289352 0.044271 0.078704 \
  0.171875 0.250000 2  0.216146 0.250000 2 \
  0.216146 0.328704 2  0.171875 0.328704 2 \
  0.193750 0.288889 2  0.182000 0.288889 2  0.205500 0.288889 2
```

## 10. 复核要点（AI 预标注后）

按风险从高到低检查：

1. **角点顺序**（最常见的错误）；
2. 角点是否被拉到墙砖缝 / 支架边缘上（`精修(R)` 之后尤其要抽查）；
3. 漏标（尤其中远距离的小靶子，一张图里常有三块板）；
4. 多标（把白球、水袋当成靶子）；
5. 圆心是否落在真实圆心上（放大镜 `L` 辅助）。

> 经验：预标注 + 逐张复核的吞吐约为纯手工的 4–6 倍。优先复核 `置信 < 0.6` 与「漏检后补标」的图片。
